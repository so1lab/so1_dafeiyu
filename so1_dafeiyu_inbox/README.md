# 大肥鱼 · dsh-pet 桌面伙伴升级组件

把文件交给大肥鱼，分析用途、生成一句简短说明，分类放入统一的资料库。双击桌宠，可以浏览、搜索、预览和调整文件位置。组件还会播放吞件、步行、投放、回程及等夸动作。无人互动时，它也会根据内部状态自主生活，并可由 DeepSeek 规划阶段活动。

当前版本 **0.19.6-test**。本组件独立维护，代码采用 MIT 许可证。

[大肥鱼动作档案](动作档案.md)列出默认模型的 125 段素材、使用情境和对话联动范围。

### 大肥鱼的记忆舱

右键桌宠选择「大肥鱼的记忆舱」。在「偏好与记忆」里设置工作时走动、桌面台词安静时段、嫌弃脸频率或性格，也可以在原版对话里发送「记住，工作时别跑来跑去」。工作状态由 dsh 提供。记忆保存在本地 `file-inbox/memory.sqlite`，和收纳索引分开，重启后仍有效。

打开记忆舱即进入「记忆星图」。行为偏好、沟通记忆、共同经历、仓库文件和动作档案分区展示，可拖动旋转、缩放、搜索和筛选。仓库星点来自当前文件与台账的核对，能查看相对位置和有效的分类调整。动作档案能预览素材，并展示已有的近期播放回执。连线来自决策引用、实际播放或同一归档批次，点星可查看详情或跳转到经历回放。星图交互参考了 [dsh-memory-brain](https://github.com/y083245/dsh-memory-brain/blob/main/public/brain.html)。

回放用播放回执串起一次桌面观察，拖动时间轴可以查看当时的阶段和动作素材示意。你可以更正偏好、查看历史版本或忘掉记忆。DeepSeek 提炼沟通重点可单独开启，后台发送限量对话文字，建议经确认后才参与聊天召回；自动生成的演出台词不转成长期事实。动作选择使用本地规则，断网时也能执行已保存的偏好。

## 0.19.6-test 桌面观察小剧场

桌面观察会依次播放发现、小跑、趴下偷看和「一脸嫌弃」。在「大肥鱼的生活」单独开启「DeepSeek 桌面台词」后，大肥鱼会复用 dsh 中已配置的 DeepSeek，发送当前文件名和最多 900 字可提取正文，生成一句文件判断和一句轻松吐槽。两句用原生气泡显示，时机跟随动画进度。没有及时拿到模型回复时，动作继续完成。

图标定位与发现动画并行。图标可见时，发现动作播完直接接小跑。窗口遮挡只暂停靠近，后续文件仍可触发发现。拖动松手后仅留短暂稳定期，移动取消时同时停掉跑步画面。

## 0.19.5-test 发现动作即时反馈

修复桌面出现新文件却看不到相应动作的问题。新文件稳定后，大肥鱼会先立即播放“发现有文件”；这个反应不再依赖文件图标是否被当前窗口遮挡。只有“普通小跑靠近 → 偷偷看文件”需要等待桌面图标可见并能准确定位。每个排队文件只播放一次发现动作，等待期间不会重复表演。

## 0.19.4-test 偷偷看文件动作

将用户提供的 9 秒视频处理为 640×360、24fps、VP9 透明动作“偷偷看文件”。保留站立、坐下观察、惊讶、趴低偷看和重新起身的完整表演，移除绿幕、音轨及角落生成标记，并按脚底位置稳定画面。

桌面新文件流程更新为“发现有文件 → 蹑手蹑脚靠近 → 偷偷看文件 → 待机”。偷看动作与前两段共用同一任务占用令牌，随机动作不能插入；动作播放期间持续核对任务令牌和文件图标，用户拖动、菜单/聊天、固定桌宠或目标移动时会停止后续流程。

## 0.19.3-test 发现文件与蹑手蹑脚靠近动作

将用户提供的“发现有文件”和“蹑手蹑脚走路”视频处理为 dsh-pet 可直接播放的 640×360、24fps、VP9 透明 WebM。处理时移除绿幕、音轨和角落生成标记，按脚底基准稳定角色位置，避免源视频横向漂移变成桌宠抖动。

“发现有文件”保留约 4 秒完整表演，只播放一次；“蹑手蹑脚走路”从侧身步态中提取 1.375 秒平滑循环。桌面观察确认文件图标可见、桌宠空闲后，先播放发现动作，再以约 105 像素/秒的慢速蹑手蹑脚靠近。位移按视频帧变化相位推进，视频停顿时窗口不会继续滑动。

两个动作属于同一次系列任务，沿用任务占用令牌。发现、走路期间，随机动作、工作状态动作、碎碎念和余额动画不能抢占；用户拖动、投喂、菜单/聊天、目标移动或不可见仍会安全取消靠近。即时文字提示继续在元数据稳定后出现，不需要等 4 秒动作结束。

## 0.19.2-test 加快发现与即时反馈

桌面文件事件到达后立即建立候选，大小和修改时间连续稳定 400 毫秒后记录发现。稳定窗口到期单独唤醒确认，不再等待下一次整秒兜底轮询；写入期间仍会延后确认，下载中和临时文件继续忽略。发现时立即显示文件名，走到旁边后另显示到达提示。任务、用户交互、桌面可见性等出发条件不变，发现不等于已经出发。

本机真实文件写入测试中，最后一次写入到发现约 0.42 秒；此结果是测试样本，不是所有设备或桌面负载下的时延保证。

## 0.19.1-test 系列任务动作保护

新增独立任务占用令牌，覆盖接件、等待识别、施法、步行、投放、回程及等夸的完整流程，也用于桌面新文件靠近。任务执行期间暂停原版随机链、动画结束后的事件轮换、工作状态切动作及碎碎念/余额动画；关闭自主生活时仍然有效。气泡可独立显示，显式用户操作和取消仍可停止位移。

多个占用重叠时，仅在最后一个任务完成或取消后恢复自动动作；旧生活采样的 busy:false 不能提前解除任务占用。失败后回到待机的收尾也纳入占用。新增测试对安装中的 dsh-pet 原版播放和事件代码逐段注入自动事件，检查动作、位移和视频结束回调未被替换。

## 0.19.0-test 桌面新文件靠近测试

在“大肥鱼的生活”中开启 **桌面新文件靠近测试**。此开关在代码默认配置中关闭；开启时先建立个人桌面一级目录的存量快照，只处理之后新出现的普通文件。大小、修改时间连续稳定约 0.4 秒后，读取文件名、完整路径和图标坐标，再慢慢走到图标旁边。文件仍在原位置，不读正文，不打开文件或文件夹，不自动分类、移动或回收。

只观察 Electron 返回的真实个人桌面路径，兼容系统重定向；不递归子文件夹。已有文件改名不当作新增，尚未确认的新建文件改名后识别最终名称；忽略点号开头的文件、desktop.ini、下载中和临时文件。多文件短时间出现时保留发现记录，靠近队列最多五个，等待超过两分钟的行程跳过，不积压漫游。

目标必须是实际可见的桌面图标。优先通过只读 Windows Shell 接口按完整路径匹配，兼容此机没有 UI Automation 图标节点的桌面；旧系统回退到 UI Automation 时，跳过无法唯一匹配的同显示名。桌面被其它窗口覆盖或隐藏图标时，等待而不猜坐标，不自动最小化窗口。用户拖动桌宠、投喂、打开菜单/聊天、固定桌宠或环境切换会取消/推迟靠近；未完成的旧位移不会覆盖新任务。发现和到达是两条独立事实，不会把未到达说成已到达。

面板显示观察阶段、最近文件名及路径。完整路径仅保存在本机，发给聊天/生活规划的经历会移除 path 字段；新增文件名称可能进入对话和阶段规划上下文。关闭开关会停止监听、清空待办靠近并取消当前行程。安静陪伴、原版显式睡眠或用户任务期间不开始自动靠近。

这是实验功能，需桌面图标可见，混合 DPI 多屏仍需更多实测。建议先放一个有独特名称的小文本文件；不要把“出现新文件”解释成确定由用户下载或创建。

## 0.18.0 连续经历与共同事实

新增本地事实日志，区分活动准备、真实播放、暂停、完成、失败和中断。生活面板展示实际播放状态，并单独保留阶段打算。动作播完回到待机后，不再仅按计划计时显示原活动。视频失败或没有收到播放回执时，不记录为已完成。

记录点击、拖动方向、稳定放置、文件拖入但未投放、投喂数量、排队与开始、逐份归档、批次合计、分类纠正和仓库打开等事件。文件归档和送件演出分别记录；同一批逐份记录与合计不重复累加。不会推测用户为什么拖动，也不读取其它应用的正文来推断用户意图。

被打断时保留原活动、阶段、原因及后续策略。拖动后留在用户选择的位置，不恢复旧散步坐标；文件任务优先。生活面板可手动继续最近十分钟内的观察、伸展、玩耍或休息，实际会重新播放一段安全的原地活动，不恢复旧 Promise、旧路线或窗口操作。未手动恢复时，根据当前情境重新安排，并保留原中断经历供模型参考。

原版聊天与阶段规划现在使用同一份事实。明确询问“现在在干什么、我刚才做了什么、为什么停下”时，直接用已确认事实生成简短回执，不依赖模型生成，也不混入旧聊天内容；其它普通聊天仍由原版模型生成并附带事实上下文。收到聊天消息也会作为事件记录，但不复制聊天正文到经历日志。可问“刚才你在干什么”“我刚才对你做了什么”“那两份文件归到哪里了”。聊天会附带实际状态、上一次重要中断、近期事件与问题相关的旧事件；状态超过十五秒未刷新则标记未知。生成回答仍可能有误，事实不足时提示模型明确说明无法确认；对话生成内容不作为新经历写回。

事实保存在 Electron userData 的 `file-inbox/experiences.jsonl`，最多保留最近两千条，重启后继续读取。渲染端有即时上报及带确认重传，重复事件按 ID 去重；进程退出前未确认结束的活动在恢复时记为中断，不补播。文件分类目录名称、数量及活动事实会进入聊天/规划上下文，不发送文件正文或完整路径；文件分类接口本身仍按原有方式处理正文样本。升级前的旧生活调度日志不会被当作已确认事实导入，不能据此追溯所有历史操作。

新增聊天上下文接入点，需要退出并重新启动 dsh 应用本身。仍支持 dsh-pet 0.4.7 / 0.4.9；安装器会校验聊天入口，卸载时移除本组件的上下文接入。

## 0.17.0 DeepSeek 阶段规划

自主生活默认开启 DeepSeek 规划。复用 dsh 已配置的模型服务，不另外填写密钥：当前默认模型属于 DeepSeek 时直接使用，否则从已配置的 DeepSeek 提供商中选择文本模型，优先官方提供商的 Flash/Chat 模型；不改聊天默认模型。未配置或调用失败时继续本地活动，生活面板显示具体状态。

模型依据当前时段、空闲时间、内部状态、允许活动及最近八条小经历，安排两到四段活动。只发送这份压缩状态，不发送文件名、正文、窗口标题、截图、坐标或完整历史。模型不会操作文件，也不会直接选动画或系统命令。计划到下一次活动边界才执行，等待期间原活动正常继续。动作时长、可用素材、用户忙碌程度、散步条件、冷却和任务优先级仍由本地引擎检查。

投喂、拖动、菜单/聊天、锁屏、全屏、休眠、关闭自主生活或切换安静陪伴时，旧计划失效。返回结果带情境版本，过期结果不会重新覆盖用户任务。请求本地超时 23 秒，宿主流式生成限制 20 秒；请求未真正结束前不会叠加新的调用。正常规划至少间隔五分钟，同一运行周期所有宠物合计每小时最多六次；失败采用退避，不会每两秒重试。

在“大肥鱼的生活”中可以关闭 **DeepSeek 规划**、查看阶段打算、实际模型、回退原因和当前活动来源。**重新规划**仍遵守调用间隔与次数限制。重启不会恢复旧计划或补发积压请求；只恢复原有生活状态。`life-state.json` 中的 `planning` 是最近诊断快照，不用于恢复计划。

新增宿主路由需要重启 dsh 应用本身；仅重启桌宠无法刷新宿主内存里的路由。升级后如果提示模型服务不可用，请确认 dsh 已配置可用 DeepSeek，再重启 dsh。

## 0.16.0 自主生活初版

无需点击或投喂，大肥鱼也会根据时间、系统空闲和内部状态，在安静陪伴、观察、伸展、自娱、短距离散步与休息之间选择。日常动作有持续时间、冷却和重复限制；用户操作时减少活动，长时间空闲后更可能打盹。自主入睡包含开始、循环与起床过渡，显式投喂会立即让位，不必等待起床动画。

双击桌宠，仓库顶部点击 **大肥鱼的生活**，可以查看当前活动、简要状态及最近的小经历，也可以关闭自主生活或切换 **安静陪伴**。安静陪伴暂停自主散步、玩耍等活动，聊天与文件整理仍可使用。关闭自主生活会恢复 dsh-pet 原有随机动作，因此如需更少动作，请选择安静陪伴。

0.16.0 的生活决策在本地执行；0.17.0 已加入可关闭的 DeepSeek 阶段规划，原有文件分析仍复用宿主模型。生活系统只读取时间、系统空闲、锁屏/休眠以及前台窗口几何，不采集窗口标题、正文或截图，不扫描桌面文件。全屏时保持安静；窗口几何采集不可用时禁止自主散步。窗口边缘攀爬和自动绕行暂未实现。

自主散步仅在用户暂时空闲且处于屏幕边缘时触发，使用送件步态的视频相位驱动水平位移，距离最多约 110 个本地像素（随宠物大小缩小）。固定位置的宠物不会自主散步；其它角色只使用自身已配置的动作，不借用大肥鱼素材。前台窗口覆盖当前位置时也不会主动散步。

文件任务从接件到整条送件演出结束持有身体占用；空闲动作不能覆盖吞件、施法、投放、回程和等夸。上游显式睡眠、占用锁、聊天、菜单和拖拽保持优先。自主行为不移动资料、不打开文件夹。

生活状态保存在 Electron userData 下 `file-inbox/life-state.json`，与文件索引分开。保存精力、困倦、兴致、好奇、用户放置的位置与最多 40 条小经历，约每 30 秒以及退出/休眠时写盘。拖动结束且位置稳定后才更新位置偏好；重启时在当前屏幕范围内恢复。关闭电脑期间只估算休息恢复，不补播活动，也不虚构完成任务。强制结束进程可能丢失最近 30 秒的状态。

这是自主生活的第一版。以下虚拟时钟和真实视频测试验证执行逻辑；真实全天使用的活动频率、趣味性与设备资源消耗仍需要继续观察和调整。

## 与 dsh-pet 的关系

需要先安装并能正常运行 dsh-pet 的 Windows 桌面宠物。组件在解包的插件目录中接入现有桌面 helper。

| 部分 | 提供能力 |
| --- | --- |
| dsh / dsh-pet | 角色、桌面窗口、模型配置、原有聊天及动画播放 |
| 本组件 | 文件分类、真实移动、索引、仓库界面、送件流程、自主生活及阶段规划 |
| DeepSeek | 利用提取文本和相关资料库案例辅助判断用途与归属 |

文件分类使用 dsh 宿主当前的默认模型。请先在 dsh 中配置可用的 DeepSeek 提供商，并将其选为默认模型。本组件无需再次填写 API Key。未选中 DeepSeek、请求失败或返回格式不合法时，会使用本地规则分类。

本地验证环境为 Windows、dsh-pet 0.4.7 / 0.4.9、Python 3.12。代码要求 Python 3.10+。其他上游版本需要核对接入点兼容性。

上游安装与项目信息见 [PC2005-cloud/dsh-pet](https://github.com/PC2005-cloud/dsh-pet)。

## 安装

1. 在 dsh 中安装 dsh-pet，确认桌宠可以正常显示。
2. 安装 Python 3.10 或更新版本，确认终端中的 python --version 可用。
3. 下载仓库完整 ZIP 并解压，进入 so1_dafeiyu_inbox 目录。保留 component、assets 和 install.py 的相对位置。
4. 退出 dsh 和桌宠，在 PowerShell 运行安装器。

通过 dsh 默认配置安装时，常见插件路径如下。先确认 Test-Path 返回 True。

~~~powershell
$petPath = Join-Path $env:USERPROFILE ".dsh\profiles\desktop\node_modules\dsh-pet"
Test-Path $petPath
python .\install.py "$petPath"
~~~

自定义安装路径也可直接传入。

~~~powershell
python .\install.py "D:\你的安装位置\dsh-pet"
~~~

安装完成后，重新启动 dsh 应用本身。仅重启桌宠不能刷新宿主内存中的新增模型路由。安装器会接入宿主分析路由、桌面 helper 和拖放事件，复制组件动作，并记录本次安装所用的 Python 路径。后续请保持该 Python 环境可用。

PDF 正文提取需要可选依赖。

~~~powershell
python -m pip install pypdf
~~~

基础文本和常见 Office 文本读取使用标准库。预览格式支持取决于 Windows 与 Electron。

## 第一次投喂

1. 先用一份测试文件，拖到大肥鱼身上松手。
2. 大肥鱼吞下文件，程序分析用途并归档。**这是实际移动**，文件会离开原路径。
3. 确定最终分类目录后，桌宠施法显示目标文件夹，再走到文件夹旁投放；停留约三秒，施法收起本次打开的窗口，再返回原位播放等夸。
4. 双击桌宠，在仓库中确认文件名和实际位置。分类不合适时可以直接调整。
5. 熟悉流程后，再投喂多份资料。

默认仓库位于 Windows“文档”目录下的“大肥鱼仓库”。文档重定向至 OneDrive 时以 Windows 返回的位置为准，旧版自定义目录优先保留。

新仓库初始化工作项目、学习参考、模板素材、往来沟通、生活事务、财务票据、旅行出行、照片图片、截图录屏、视频、音频录音、软件工具等分类。旧目录尽量复用，也可以在资源管理器中新建适合自己的子目录。

本版处理用户主动投放的单个或多个文件，跳过目录投放，不提供全桌面扫描。

### 投喂操作

| 操作 | 效果 |
| --- | --- |
| 直接拖入文件 | 自动分类并收纳 |
| 按住 Alt 投放 | 打开搬运方式选择，可选择目录或回收站 |
| 按住 Shift 投放 | 保留 dsh-pet 原有图片聊天行为 |
| 双击桌宠 | 打开文件管理主页 |
| 收纳选项中的精简动画 | 使用精简整理演出 |

### 文件管理

- 单击选中，Ctrl 多选，Shift 连选。
- 双击文件用默认应用打开；可执行程序等交给资源管理器定位。
- 空格或点击类型图标预览。支持的图片显示大图，其余展示说明、位置和操作。
- 点击文件行中的“位置 ▾”，就地搜索并选择新目录。
- 拖到可见目录或常用位置，实际移动文件。
- 选中多份文件后使用“移动到…”批量调整。
- 在目录内点击“固定此处”加入常用位置。
- 右上角“移动历史”查看来源、去向及撤销状态，底部可撤销最近调整。
- 更多菜单中可以打开资源管理器或查看收纳回放。回放按投喂批次查看，改放之后仍可在原批次找到文件。

同名目标自动追加编号并保留两份。文件被占用、内容变化或撤销目标被其他文件占用时会报告错误。批量操作可能部分完成，需查看成功数量和失败提示。

## 纠正与学习

人工移动会记录为归类案例。新文件进入时，会检索资料库以及未撤销的人工调整，选出相关示例交给 DeepSeek。一次批量操作按一次整理事件计入参考。撤销时撤回对应记录，文件再次改放后不再按原目录作为纠正示例。

这是本地案例检索和提示上下文增强，没有训练或微调模型。固定目录只影响导航。相似文件建议由用户主动选择，不会因一次手动移动就改动整库文件。

## 数据与隐私

真实资料在仓库目录中。索引、设置和历史存放在 Electron 用户数据目录的 file-inbox 下，常见位置为 %APPDATA%\dsh-pet-electron-helper\file-inbox。

调用 DeepSeek 时会经 dsh 原有接口发送文件名、有限长度的提取文本、候选目录和相关历史案例。索引和历史在本地保存。仓库源码不包含 API Key、个人配置、数据库或个人文件。

当前没有通用 OCR、图像视觉识别或视频内容理解。图片及视频主要根据名称、格式和库内上下文判断，缩略图用于人工查看。

## 升级与卸载

升级前备份仓库以及 file-inbox 数据目录，关闭桌宠，下载新版完整组件，重复运行安装命令，再重启。

~~~powershell
python .\install.py "$petPath"
~~~

上游 dsh-pet 更新可能覆盖接入点，需要重新安装组件。若报告入口不兼容，应先适配上游版本。

卸载接入点后重启 dsh。

~~~powershell
python .\install.py "$petPath" --uninstall
~~~

卸载会保留个人仓库、数据库和额外动画素材。旧缓存可能使组件目录保留。个人数据由用户自行管理。

## 动画限制与故障处理

送件使用真实文件夹坐标。当前流程确定最终目标后一次走到目标，目标位置变化时结束该次演出，避免追赶和反复开窗。多目录送件优先复用本次打开的资源管理器窗口。

**吞咽到起步仍可能等待分类、开窗和图标定位。** 完整真实 DeepSeek 投喂的连续录屏、多显示器混合 DPI、持续拖动资源管理器等场景尚未全部验收。

- 文件已移走但动画失败时，先打开仓库搜索文件。归档成功和桌面演出成功有各自条件。
- 没有 DeepSeek 效果时，检查宿主默认模型及提供商名称是否包含 DeepSeek，并确认模型请求正常。
- 看不到新界面时，核对安装位置是否属于当前 desktop 配置，并彻底重启桌宠。
- 安装提示入口不匹配时，保留报错并核对上游版本，避免手工删改入口标记。

## 0.15.0 施法开合动作

新增用户视频制作的透明动作 小小魔法-开合.webm，24fps、3.5秒，保留原速及星光。开与关复用同一素材，第1.8秒释放星光时才发起窗口操作；窗口准备与剩余收势并行，二者完成后才开始送件或回程。

吞件阶段仅预热定位进程，不提前打开窗口。窗口关闭继续沿用所有权、目录和标签页检查，用户接管的窗口保留。视频加载失败或被拖动打断时不继续演出；文件归档结果独立保留。
