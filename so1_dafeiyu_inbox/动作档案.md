# 大肥鱼动作档案

按本机 dsh-pet 0.4.9 默认大肥鱼模型的已安装素材逐项核对。共 **125 段动作素材**，其中 **81 段**在宿主的对话白名单中，另有 44 段由系统或任务调度。睡眠的开始、循环、起床各自占一个素材条目。

[程序可读取的动作目录](component/action-catalog.json)使用素材原名作为动作键。宿主现有对话联动已支持选一个动作。档案里的情境和用途供后续收窄候选。

情境标签依据素材名、宿主配置和文件任务中的调用位置整理。

| 标记 | 建议如何使用 |
| --- | --- |
| 自然回应 | 可以由大肥鱼根据语气选一个。正事或没有合适的动作时直接回答。 |
| 匹配话题 | 食物、节日和固定文案要切合当前话题。 |
| 优先点播 | 舞蹈、乐器、游戏和夸张小剧场优先响应用户的明确邀请。 |
| 系统事件 | 按真实点击、拖拽、工作状态、余额或睡眠阶段触发。 |
| 受控任务 | 由文件或桌面任务在对应阶段触发，移动循环沿用现有位移控制。 |

正式接入动作记忆时，动作档案描述能力。播放记录应另外保存动作键、情境、开始与结束回执、中断原因和明确反馈。只有收到播放回执才记为做过。对话待选动作要同时存在于当前模型素材和宿主白名单，文件任务、拖拽或睡眠占用期间交给原有调度。
